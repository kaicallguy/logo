🚀 GitHub Pages 免費架站教學

如何將這套首頁與數學網頁放上 GitHub Pages？

只需將檔案放進你的 GitHub Repository，免費擁有自己嘅公開溫習網站：

1

上傳首頁 (index.html)

將本檔案儲存為 index.html，直接放在 Repository 的根目錄 (Root)。

2

放進數學專題網頁

將之前生成的數學救亡網頁改名為 math.html，與 index.html 放在同一個目錄。

3

開啟 GitHub Pages

到 Repo 的 Settings > Pages，在 Branch 選擇 main / (root) 並儲存，等待 1 分鐘即可上線！
